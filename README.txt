AutoSklep - mod kliencki Fabric dla Minecraft 1.21.4
Gdy ekwipunek zapelni sie miedzia: wysyla komende sklepu, klika czerwona welne,
klika miedz, zamyka sklep (jak ESC) i powtarza.

KLAWISZE
G  - okno ustawien (GUI), tu wpiszesz komende, np. sklep albo repair
H  - wlacz/wylacz
/autosklep [start|stop|gui|status|cmd <komenda>]

BUDOWANIE: najprosciej przez GitHub Actions (plik .github/workflows/build.yml),
jar pojawi sie w zakladce Actions -> Artifacts.
Mod wrzucasz do .minecraft/mods razem z Fabric Loader i Fabric API 1.21.4.

UWAGA: sprawdz regulamin serwera - automatyzacja moze byc zabroniona.
